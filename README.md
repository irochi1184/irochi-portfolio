# irochi Vtuber風ポートフォリオサイト

Vtuber的でポップな印象に寄せた、イラストポートフォリオの静的サイトです。
青緑系を基調に、かわいい女の子イラストが目立つ見せ方へ改良しています。

## 今回の変更点
- かっこいい雰囲気から、ポップでかわいい方向へ全体デザインを変更
- 青緑系を基調色に調整
- いただいた作品画像を実際に作品一覧へ組み込み
- Vtuberっぽい丸みのある見た目、ポップな見出し、やわらかい配色へ変更
- ご依頼や料金表もかわいい印象で見やすく再構成

## ファイル構成
- `index.html` … サイト本体
- `style.css` … デザイン
- `script.js` … メニュー、絞り込み、拡大表示
- `assets/` … 作品画像

## 連絡先の差し替え
以下は仮置きなので変更してください。
- メール: `yourmail@example.com`
- Xリンク: `#`

## 料金表の変更
`index.html` 内の「ご依頼・料金表」セクションを変更すれば調整できます。

## 作品を追加する方法
1. `assets` フォルダへ画像を追加
2. `gallery` 内の `work-card` を複製
3. `src` と `alt` と見出し文言を差し替え
4. `data-category` を `girl` `stream` `event` `other` のいずれかに設定
