irochi-portfolio だけを編集できる Fine-grained Personal Access Token を入力します。 トークンはこのページ内の処理だけに使い、GitHubリポジトリには保存しません。

初回だけ：トークンの作り方
  1. GitHubの Settings → Developer settings → Personal access tokens → Fine-grained tokens を開く
  2. Repository access は「Only select repositories」で irochi-portfolio だけを選ぶ
  3. Repository permissions の Contents を「Read and write」にする
  4. 作成したトークンをこの欄へ貼り付ける
